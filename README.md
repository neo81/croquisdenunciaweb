# ProyectoCanvas
# 🚗 Denuncia de Siniestros de Autos (Croquis)

Este proyecto es una aplicación web interactiva desarrollada en **Angular** que permite a los usuarios recrear escenas de accidentes viales de forma gráfica y técnica.

## 🛠️ Tecnologías utilizadas
* [Angular 18+](https://angular.io/) - Framework principal.
* [Konva.js](https://konvajs.org/) - Librería para el manejo de Canvas 2D.
* [GitHub](https://github.com/) - Control de versiones.

## ✨ Funcionalidades principales
* **Dibujo a mano alzada:** Permite trazar trayectorias con diferentes colores.
* **Biblioteca de iconos:** Arrastrar y soltar (Drag & Drop) vehículos y señales.
* **Manipulación de objetos:** Rotar, escalar, duplicar y voltear (flip) elementos.
* **Persistencia JSON:** Capacidad de guardar el estado del croquis y recargarlo más tarde.
* **Exportación:** Descarga del croquis final en formato PNG de alta calidad.

## 🚀 Instalación y Uso
1. Clona el repositorio.
2. Ejecuta `npm install` para instalar las dependencias.
3. Corre el proyecto con `ng serve`.
4. Abre `http://localhost:4200` en tu navegador.
